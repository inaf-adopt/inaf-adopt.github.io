## Publication provenance

`orcid-publications.js` is a dated snapshot of publication summaries from `https://pub.orcid.org/v3.0/{ORCID}/works`. Only public journal articles, conference papers/abstracts, preprints, books/chapters, reviews and theses with a title, publication year through 2026 and a source link are included. Grouped work summaries are deduplicated by DOI and by identical long title plus year. No author order is inferred from an ORCID record association. Entries retain the originating ORCID identifiers.

`member-publications.js` contains manually checked bylines and member associations, with a source URL for each. Publisher-deposited Crossref author lists were used to extend these associations and the first/second-author metadata in `project-papers.js`. The Population III black-hole paper has Santoliquido and Mapelli as its first two authors; Merli is a coauthor, not its first author.

`publication-catalogue.js` merges the project, curated-member and ORCID lists. The default view uses only verified first/second authorship. ORCID-derived records are exposed in the member and full bibliography views, with visible source links. Publications are displayed only in the central catalogue; member pages contain the explicit ORCID links.

## Updating

Update verified identity fields in `people-data.js`. Refresh the public works snapshot only from the matching ORCID identifiers and preserve provenance. Update checked bylines separately; never promote an ORCID-only work to the first/second-author view without checking author order. Run `node scripts/build-people.cjs` after data changes and commit the regenerated pages. This is a snapshot, not automatic synchronisation.
