Use your GitHub account

Choose your own profile and edit the fields below. This prepares a draft in your browser; it does not change the public website.

  1. Make your changes, then select Prepare update.
  2. Copy the prepared text and open the GitHub editor. Sign in to GitHub if prompted.
  3. Replace the file contents with your copied text, choose Propose changes, and open a pull request.
  4. A website administrator checks the update and your identity before publishing it.

GitHub may ask you to fork the repository first. No password or access token is entered on this website.
