Privacy

This prototype does not install analytics or receive search queries on a server. The optional language selector uses GTranslate, a third-party automatic-translation service that loads external JavaScript when a page is visited. Its availability and privacy practices are governed by the provider. Machine translations can contain errors; the English text is authoritative. External links lead to their own services.
